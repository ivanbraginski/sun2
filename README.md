# 好物知识库 · 品牌音浪榜

B 站 @大物是也「好物分享」合集 + @王阿姨呀呦「Yi马当鲜」+ @皮科医生魏小博 + @逛拼多多的品检员 好物整理。

- **3080** 条好物条目 · **1302** 个品牌 · **78** 个高频品牌(≥5次) · **70** 个视频/来源
- 态度分布：推荐 2347 / 争议 194 / 避雷 147 / 提及 392
- 数据来自 B 站官方语音字幕及公开购物清单整理，内容归属原作者，仅供个人参考
