# 大物是也 · 好物知识库

B 站 @大物是也「好物分享」合集 + @皮科医生魏小博 视频中的好物整理。

- **2089** 条好物条目 · **661** 个品牌 · **68** 个视频
- 数据来自 B 站官方语音字幕自动整理，内容归属原作者，仅供个人参考

## 文件
- `index.html` — 可搜索/筛选的知识库网页（浏览器直接打开）
- `products.json` — 全部好物结构化数据（2089 条）
- `brands.json` — 品牌索引（661 个）
- `大物是也好物知识库.xlsx` — Excel 明细表（好物明细/品牌索引/视频清单）

## 字段
品牌、产品名、类别、态度（推荐/争议/避雷/提及）、推荐人、价格、来源视频、时间点、原文佐证、备注。
